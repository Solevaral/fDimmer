# fDimmer

<img src="assets/icon.png" width="96" height="96" alt="fDimmer icon">

[English](README.md) · **Русский**

Затемнение экрана для Windows 10/11, которое распространяется **на всё** — включая
переключатель Alt+Tab, меню «Пуск», панель задач, всплывающие уведомления, окна чужих
приложений (в том числе запущенных от администратора) и все мониторы сразу.

## Скачать

Свежая сборка — в разделе [Releases](https://github.com/Solevaral/fDimmer/releases):

- `fDimmer-<версия>-win-x64-standalone.exe` — запускается как есть, рантайм не нужен.
- `fDimmer-<версия>-win-x64-net9.exe` — маленький, требует .NET 9 Desktop Runtime.

Установщика нет: положите файл куда угодно и запустите. Приложение живёт в области
уведомлений; чтобы оно возвращалось после перезагрузки, включите в меню **Запускать
с Windows**.

**Только Windows.** Главное свойство приложения — затемнение системных окон — держится
на цветовом эффекте DWM, аналога которому за пределами Windows нет. В KDE для этого есть
встроенные ночной режим и управление яркостью.

## Чем отличается от DimScreen и подобных

Обычные диммеры рисуют полупрозрачное чёрное окно поверх экрана. Такое окно принципиально
не может перекрыть системные поверхности: Alt+Tab, «Пуск», панель задач и уведомления живут
в более высоких **window bands** (`ZBID_IMMERSIVE_*`, `ZBID_SYSTEM_TOOLS`), куда обычное
`HWND_TOPMOST` окно не попадает. Обойти это оверлеем можно только через недокументированный
`SetWindowBand()`, требующий UIAccess — подписанный сертификатом бинарник, установленный
в `%ProgramFiles%`.

fDimmer идёт другим путём: **Magnification API**, функция `MagSetFullscreenColorEffect`.
Она задаёт цветовую матрицу 5×5, которую DWM применяет к итоговой композиции рабочего стола.
Затемняется не «окно поверх», а сам вывод — поэтому под затемнение попадает всё, что рисует
композитор. Так же устроены штатные «Цветовые фильтры» Windows. Права администратора
и UIAccess не нужны.

## Два режима

| Режим | Как работает |
|---|---|
| **Общий** (по умолчанию) | Одна яркость на всё: окна, Alt+Tab, «Пуск», трей, уведомления, все мониторы. Цветовой эффект DWM. |
| **По мониторам** (экспериментально) | У каждого монитора своя яркость. |

Переключается в меню трея (**Режим**) и в настройках. Если общий режим недоступен (экранный
увеличитель отключён политикой), приложение само переходит в режим «По мониторам» и сообщает
об этом.

### Режим «По мониторам» — экспериментальный, может работать некорректно

Цветовой эффект DWM — одна матрица на весь рабочий стол, поэтому раздельная яркость берётся
из другого места — **гаммы** каждого монитора. Гамма затемняет весь вывод монитора, включая
системные окна. Но Windows не даёт опустить гамму ниже некоторого порога — обычно около
**50 %**. Глубже fDimmer дотемняет монитор полупрозрачным окном поверх, и эта часть затемнения
Alt+Tab и «Пуск» **уже не перекрывает**.

- Ниже порога гаммы системные окна темнеют только до этого порога.
- Конфликтует с «Ночным светом» — он тоже работает через гамму.
- В HDR гамма не действует, всю работу делает окно поверх.
- В отличие от общего режима, гамма переживает убийство процесса. Исходные таблицы
  сохраняются в `%AppData%\fDimmer\gamma-baseline.bin` и возвращаются при следующем запуске.

Порог 50 % снимается параметром `GdiIcmGammaRange` (DWORD) = `256` в разделе
`HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ICM` и перевходом в систему. Это
общесистемная настройка — меняйте её, только если точно это нужно.

## Управление

- **Колесо мыши над иконкой в трее** — меняет яркость с настраиваемым шагом. В режиме
  «По мониторам» двигает все мониторы разом, сохраняя разницу между ними.
- **Клик по иконке** — меню: вкл/выкл, пресеты 100/75/50/35/20 %, режим, пресеты для каждого
  монитора (в режиме «По мониторам»), расписание, настройки, язык, автозапуск, выход.
- **Настройки** — ползунок яркости, режим, ползунок на каждый монитор, нижний предел, шаг
  колеса, плавность перехода, индикатор на экране, язык интерфейса, автозапуск с Windows.

Язык интерфейса по умолчанию берётся из Windows, можно принудительно выбрать английский
или русский. Настройки лежат в `%AppData%\fDimmer\settings.json`.

## Расписание

Яркость может меняться по часам. Расписание — это список точек: каждая действует до
следующей, сутки замкнуты через полночь:

| Время | Яркость |
|---|---|
| 21:00 | 60 % |
| 00:00 | 40 % |
| 08:00 | 100 % (без затемнения) |

С таким расписанием с 21:00 до полуночи экран на 60 %, с полуночи до 08:00 — на 40 %,
остальное время не затемнён. Точки правятся в пункте **Расписание…** меню трея.
В режиме «По мониторам» точка расписания выставляет всем мониторам одинаковый уровень.

Уровень выставляется только в момент наступления точки, поэтому ручное изменение — колесом,
пресетом, ползунком — держится до следующей точки, а не затирается через секунду.

## Защита от «погасил экран и не вижу трей»

Яркость не опускается ниже настраиваемого предела (по умолчанию 15 %, жёсткий минимум 5 %).
Экран возвращается к норме при выходе из приложения, при завершении сеанса, при
необработанной ошибке и при принудительном завершении процесса — цветовой эффект живёт
в контексте процесса и снимается вместе с ним. В режиме «По мониторам» после убийства
процесса гамма остаётся затемнённой до следующего запуска, который её возвращает.

Уровень переприменяется после разблокировки сеанса и после смены конфигурации дисплеев.

## Известные ограничения

- **Экран UAC и Ctrl+Alt+Del** (secure desktop) не затемняются — это отдельный рабочий стол,
  недостижимый ни для одного пользовательского приложения.
- **Игры в эксклюзивном полноэкранном режиме** идут мимо DWM и не затемняются.
- **Конфликт с «Цветовыми фильтрами» Windows и Night Light** — они используют тот же слот
  цветового эффекта, последний включённый выигрывает.
- **Аппаратный курсор мыши** не затемняется.
- Обработка колеса требует, чтобы иконка была **закреплена** в области уведомлений, а не
  спрятана в переполнении: у скрытой иконки оболочка не отдаёт координаты.

## Сборка

```bash
dotnet build fDimmer.sln -c Release
```

Одним файлом:

```bash
dotnet publish src/fDimmer/fDimmer.csproj -c Release -o publish
```

Требуется .NET 9 (framework-dependent). Целевая платформа — x64.

## Устройство кода

```
src/fDimmer/
  Program.cs                    единственный экземпляр, аварийное снятие эффекта
  Interop/Magnification.cs      P/Invoke к magnification.dll, цветовая матрица
  Interop/NativeMethods.cs      окна, мониторы, иконка трея, низкоуровневый хук мыши
  Core/DimController.cs         состояние, плавный переход, системные события, откат режима
  Core/MagnificationEngine.cs   общий режим
  Core/PerMonitorEngine.cs      режим «по мониторам»: гамма, а ниже её порога — окно поверх
  Core/GammaRamp.cs             гамма монитора, сохранение исходных таблиц на случай аварии
  Core/OverlayLayer.cs          полупрозрачные окна поверх мониторов
  Core/TrayWheelHook.cs         колесо над иконкой трея
  Core/Strings.cs               строки интерфейса: английский / русский
  Core/Settings.cs, AutoStart.cs, Scheduler.cs
  UI/TrayApplicationContext.cs  меню и склейка
  UI/TrayIcon.cs                иконка через Shell_NotifyIcon (нужны свои hWnd и uID)
  UI/DimOverlayForm.cs          click-through окно на монитор
  UI/OsdForm.cs                 индикатор уровня
  UI/SettingsForm.cs, ScheduleForm.cs
```
